@brief Plays a tone with stream information of sound-manager.

@since_tizen 3.0

@remarks Voice Recognition stream type is not supported in this API.

Parameter tone The tone type to play Parameter stream_info The sound stream information handle Parameter duration_ms The tone duration in milliseconds \n @c -1 indicates an infinite duration. Output parameter id The tone player ID ( can be set to @c NULL )

@return @c 0 on success, otherwise a negative error value @retval #TONE_PLAYER_ERROR_NONE Successful @retval #TONE_PLAYER_ERROR_INVALID_PARAMETER Invalid parameter @retval #TONE_PLAYER_ERROR_INVALID_OPERATION Invalid operation @retval #TONE_PLAYER_ERROR_NOT_SUPPORTED_TYPE Not supported stream type

@platform @brief Makes reservation for update. @details Makes update reservation at a specific time. At the given time, it automatically checks, downloads and updates to a new version. To cancel the reservation, call update_control_cancel_reservation().

@since_tizen 5.0 @privlevel platform @privilege %http://tizen.org/privilege/updatecontrol.admin @remarks Only one reservation can be used at any given time.

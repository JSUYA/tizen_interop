@return 0 on success, otherwise a negative error value. @retval #BT_ERROR_NONE Successful @retval #BT_ERROR_NOT_INITIALIZED Not initialized @retval #BT_ERROR_INVALID_PARAMETER Invalid parameter @retval #BT_ERROR_NOT_ENABLED Adapter is not enabled @retval #BT_ERROR_OPERATION_FAILED Operation failed @retval #BT_ERROR_PERMISSION_DENIED Permission denied @retval #BT_ERROR_NOT_SUPPORTED Not supported @retval #BT_ERROR_NOW_IN_PROGRESS Operation is in progress

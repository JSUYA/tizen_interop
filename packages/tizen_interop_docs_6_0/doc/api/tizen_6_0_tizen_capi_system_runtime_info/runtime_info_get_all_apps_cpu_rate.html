@brief Gets CPU rate of all apps. @since_tizen 4.0

@privlevel public @privilege %http://tizen.org/privilege/systemmonitor @remarks You must release @a rate using runtime_info_app_usage_destroy().

Output parameter rate An array of each app's CPU usage rate (%), the values are rounded down.

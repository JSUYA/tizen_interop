@brief Creates the notification_ex reporter handle. @details The reporter handle is created with event callbacks and the user can listen notification events through the event callbacks. Callbacks in @a event_callbacks can be set to NULL, which will result in the corresponding events not being received. @since_tizen 5.5 @privlevel public @privilege %http://tizen.org/privilege/notification @remarks @a handle must be released using noti_ex_reporter_destroy().

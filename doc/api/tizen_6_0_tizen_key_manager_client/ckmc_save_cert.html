@brief Stores a certificate inside key manager based on the provided policy. @since_tizen 2.3 @remarks %http://tizen.org/privilege/keymanager (public level privilege) is no longer required to use this API since 3.0 @remarks The certificate's binary value will be converted and saved as binary DER encoded certificates.

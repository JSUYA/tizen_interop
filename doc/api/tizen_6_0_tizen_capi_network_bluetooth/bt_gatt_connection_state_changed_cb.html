bt_gatt_connection_state_changed_cb = bt_gatt_connection_state_changed_cb

@ingroup CAPI_NETWORK_BLUETOOTH_GATT_MODULE @brief Called when the connection state is changed.

@details This callback is called when the connection state is changed. When you called bt_gatt_connect() or bt_gatt_disconnect(), this callback is also called with error result even though these functions fail.

@since_tizen @if WEARABLE 2.3.1 @else 2.3 @endif Parameter result The result of changing the connection state. Parameter connected The state to be changed, true means connected state, Otherwise, false. Parameter remote_address The remote_address Parameter user_data The user data passed from the callback registration function.

@see bt_gatt_connect() @see bt_gatt_disconnect() @see bt_gatt_set_connection_state_changed_cb() @see bt_gatt_unset_connection_state_changed_cb()

Register this callback with TizenInteropCallbacks.register<bt_gatt_connection_state_changed_cbFunction>() from package:tizen_interop_callbacks. Pass RegisteredCallback.interopCallback and RegisteredCallback.interopUserData to the native API. Used by: bt_gatt_set_connection_state_changed_cb.

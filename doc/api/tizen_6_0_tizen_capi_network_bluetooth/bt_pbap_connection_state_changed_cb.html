@WEARABLE_ONLY @ingroup CAPI_NETWORK_BLUETOOTH_PBAP_MODULE @brief Called when PBAP is Connected or Disconnected. @details The following error codes can be delivered: \n #BT_ERROR_NONE \n #BT_ERROR_AUTH_REJECTED \n #BT_ERROR_AUTHORIZATION_REJECTED \n #BT_ERROR_SERVICE_NOT_FOUND \n #BT_ERROR_TIMED_OUT \n #BT_ERROR_OPERATION_FAILED \n @since_tizen 3.0

Parameter result The result of connecting to or disconnecting from the remote device Parameter connected The PBAP connection status (@c true = connected, @c false = disconnected) Parameter remote_address The remote device address (@a remote_address is valid only inside this function. To use outside the callback, make a copy. @a remote_address should not be freed.) Parameter user_data The user data passed from the callback registration function @see bt_pbap_client_connect() @see bt_pbap_client_disconnect()

Register this callback with TizenInteropCallbacks.register<bt_pbap_connection_state_changed_cbFunction>() from package:tizen_interop_callbacks. Pass RegisteredCallback.interopCallback and RegisteredCallback.interopUserData to the native API. Used by: bt_pbap_client_set_connection_state_changed_cb.

ime_mime_type_set_request_cb = ime_mime_type_set_request_cb

@brief Called when an associated text input UI control requests the text entry to set the MIME type.

@since_tizen 4.0

@privlevel public

@privilege %http://tizen.org/privilege/ime

@remarks @a mime_type is valid only in the callback. To use outside the callback, make a copy. This function is used by the applications to deliver the MIME type to the input panel.

Parameter mime_type The MIME type to be set to the input panel Parameter user_data User data to be passed to the callback function

@pre The callback can be registered using ime_event_set_mime_type_set_request_cb() function.

@see ime_event_set_mime_type_set_request_cb()

Register this callback with TizenInteropCallbacks.register<ime_mime_type_set_request_cbFunction>() from package:tizen_interop_callbacks. Pass RegisteredCallback.interopCallback and RegisteredCallback.interopUserData to the native API. Used by: ime_event_set_mime_type_set_request_cb.

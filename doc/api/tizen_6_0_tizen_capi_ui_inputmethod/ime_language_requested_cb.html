@brief Called when an associated text input UI control requests the language from the input panel.

@since_tizen @if MOBILE 2.4 @else 3.0 @endif

@privlevel public

@privilege %http://tizen.org/privilege/ime

@remarks The allocated @a lang_code will be released internally.

Parameter user_data User data to be passed from the callback registration function Output parameter lang_code Input panel's current input language code (e.g., "en_US")

@pre The callback can be registered using ime_event_set_language_requested_cb() function.

@see ime_event_set_language_requested_cb()

Register this callback with TizenInteropCallbacks.register<ime_language_requested_cbFunction>() from package:tizen_interop_callbacks. Pass RegisteredCallback.interopCallback and RegisteredCallback.interopUserData to the native API. Used by: ime_event_set_language_requested_cb.

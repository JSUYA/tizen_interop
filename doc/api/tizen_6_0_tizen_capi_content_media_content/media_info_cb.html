@ingroup CAPI_CONTENT_MEDIA_INFO_MODULE @brief Called for every available media info. @details Iterates over a list of media info. @since_tizen @if MOBILE 2.3 @elseif WEARABLE 2.3.1 @endif

@remarks To use the @a media outside this function, copy the handle with media_info_clone() function. \n The callback is called in the main loop.

Parameter media The handle to the media info Parameter user_data The user data passed from the foreach function

@return @c true to continue with the next iteration of the loop, otherwise @c false to break out of the loop

@pre media_tag_foreach_media_from_db(), media_playlist_foreach_media_from_db(), media_genre_foreach_media_from_db(), media_info_foreach_media_from_db(), media_folder_foreach_media_from_db() will invoke this function.

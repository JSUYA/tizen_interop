@brief Called when the Application Service Platform (ASP) reports progress on group formation. @since_tizen 4.0 @remarks @a deferred_resp is valid only in the callback. To use outside the callback, make a copy. Parameter error_code The error code.\n #ASP_ERROR_NONE Successful\n #ASP_ERROR_OUT_OF_MEMORY Out of memory\n #ASP_ERROR_OPERATION_FAILED Operation failed\n Parameter session The session for which progress is reported; the handle to the same object for which the callback was set Parameter status The connection progress status Parameter deferred_resp The service-specific data payload up to 144 bytes Parameter resp_size The service-specific data payload size(up to 144) Parameter user_data The user data passed from the callback registration function @pre The callback must be registered using asp_session_set_connect_status_cb() @see asp_session_set_connect_status_cb()

Register this callback with TizenInteropCallbacks.register<asp_session_connect_status_cbFunction>() from package:tizen_interop_callbacks. Pass RegisteredCallback.interopCallback and RegisteredCallback.interopUserData to the native API. Used by: asp_session_set_connect_status_cb.

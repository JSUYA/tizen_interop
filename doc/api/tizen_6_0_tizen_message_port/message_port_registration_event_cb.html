message_port_registration_event_cb = message_port_registration_event_cb

@brief Called when a remote port is registered or unregistered. @details The function is called when a remote port is registered or unregistered from the remote application. @since_tizen 4.0 @remarks @a remote_app_id and @a remote_port can be used until message_port_remove_registration_event_cb() is called for the watcher which reported the event. Parameter remote_app_id The ID of the remote application that sent this message Parameter remote_port The name of the remote message port Parameter trusted_remote_port Indicates whether remote port is trusted Parameter user_data The user data passed from the register function @pre Called when a remote port is registered or unregistered if you add it using message_port_add_registered_cb() or message_port_add_unregistered_cb() respectively. @see message_port_add_registered_cb() @see message_port_add_unregistered_cb() @see message_port_remove_registration_event_cb()

Register this callback with TizenInteropCallbacks.register<message_port_registration_event_cbFunction>() from package:tizen_interop_callbacks. Pass RegisteredCallback.interopCallback and RegisteredCallback.interopUserData to the native API. Used by: message_port_add_registered_cb, message_port_add_unregistered_cb.

app_watchdog_timer_enable function

int app_watchdog_timer_enable()

@brief Sends the enable request to activate the watchdog timer. @since_tizen 5.5 @remarks After this function is called, the system detects a timeout error. If, due to a program error as ANR (Application Not Responding), the system fails to reset the watchdog, the timer will elapse and generate a signal to terminate the running application. If the running application has to process a lot of operations, the application should disable or reset the watchdog timer. @return @c 0 on success, otherrwise a negative error value @retval #APP_ERROR_NONE Successful @retval #APP_ERROR_INVALID_CONTEXT Invalid context @see app_watchdog_timer_disable() @see app_watchdog_timer_kick()

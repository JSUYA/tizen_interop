media_packet_finalize_cb = media_packet_finalize_cb

@brief Called when the media packet is destroyed. @details It will be invoked when media_packet_destroy() is called.

@since_tizen @if MOBILE 2.3 @elseif WEARABLE 2.3.1 @endif

Parameter packet The media packet handle Parameter error_code The error code of #media_packet_error_e Parameter user_data The user data passed from the callback registration function @retval #MEDIA_PACKET_REUSE Packet handle is not destroyed, the handle will be reused. @retval #MEDIA_PACKET_FINALIZE Destroy media packet handle, the handle will not be reused. @pre It will be invoked when media packet is destroyed. @see media_packet_destroy() @see media_packet_create_alloc() @see media_packet_create() @see media_packet_copy() @see media_packet_create_from_tbm_surface()

Register this callback with TizenInteropCallbacks.register<media_packet_finalize_cbFunction>() from package:tizen_interop_callbacks. Pass RegisteredCallback.interopCallback and RegisteredCallback.interopUserData to the native API. Used by: media_packet_copy, media_packet_create, media_packet_create_alloc, media_packet_create_from_external_memory, media_packet_create_from_tbm_surface.

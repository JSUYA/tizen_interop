dnssd_found_cb

dnssd_found_cb typedef

dnssd_found_cb = dnssd_found_cb

@brief Called when a DNSSD service is found. @details remote_service is valid only when service_state is #DNSSD_SERVICE_STATE_AVAILABLE or #DNSSD_SERVICE_STATE_UNAVAILABLE. In case of service_state #DNSSD_SERVICE_STATE_UNAVAILABLE, application can only use dnssd_service_get_type() and dnssd_service_get_name(). Other get functions can only be used when service_state is #DNSSD_SERVICE_STATE_AVAILABLE. @since_tizen 3.0 Parameter service_state The DNSSD service state of remote service Parameter remote_service The DNSSD remote service handle Parameter user_data The user data passed from the request function @see dnssd_start_browsing_service()

Register this callback with TizenInteropCallbacks.register<dnssd_found_cbFunction>() from package:tizen_interop_callbacks. Pass RegisteredCallback.interopCallback and RegisteredCallback.interopUserData to the native API. Used by: dnssd_start_browsing_service.

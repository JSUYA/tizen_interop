@deprecated Deprecated since 5.5. Use mc_client_get_server_ability_support() instead. @brief Gets the support value of the repeat ability of the updated media controller server. @since_tizen 5.0

@privlevel public @privilege %http://tizen.org/privilege/mediacontroller.client

@remarks If the server's ability support is not set, the result value is #MC_ABILITY_SUPPORTED_UNDECIDED. \n It means you can send the corresponding command to the server, but it's not guaranteed that the server can handle it.

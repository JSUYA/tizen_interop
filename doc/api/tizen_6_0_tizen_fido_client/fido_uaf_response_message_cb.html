fido_uaf_response_message_cb

fido_uaf_response_message_cb typedef

fido_uaf_response_message_cb = fido_uaf_response_message_cb

@brief Called when fido_uaf_get_response_message() response comes. @details The following error codes can be delivered:

#FIDO_ERROR_NONE                        Successful
#FIDO_ERROR_OUT_OF_MEMORY               Out of Memory
#FIDO_ERROR_USER_ACTION_IN_PROGRESS     User action is in progress.
#FIDO_ERROR_USER_CANCELLED              User has cancelled the operation.
#FIDO_ERROR_PERMISSION_DENIED           The application does not have permission to call this
function.
#FIDO_ERROR_UNSUPPORTED_VERSION         The UAF Message does not specify a protocol version
supported by this FIDO UAF Client.
#FIDO_ERROR_NO_SUITABLE_AUTHENTICATOR   No suitable authenticators found.
#FIDO_ERROR_PROTOCOL_ERROR              The interaction may have timed out, or the UAF message
is malformed.
#FIDO_ERROR_UNTRUSTED_FACET_ID          The caller's id is not allowed to use this operation.

@since_tizen 3.0

Parameter tizen_error_code Tizen platform error code Parameter uaf_response_json FIDO response message in JSON format Parameter user_data The user data passed from the callback function

@pre fido_uaf_get_response_message() must be called to get this callback invoked. @see fido_uaf_get_response_message()

Register this callback with TizenInteropCallbacks.register<fido_uaf_response_message_cbFunction>() from package:tizen_interop_callbacks. Pass RegisteredCallback.interopCallback and RegisteredCallback.interopUserData to the native API. Used by: fido_uaf_get_response_message.

mv_inference_supported_engine_cb = mv_inference_supported_engine_cb

@brief Called to provide information for supported engines for inference.

@since_tizen 5.5

Parameter engine The supported engine. The @a engine can be used only in the callback. To use outside, make a copy. Parameter supported The flag whether the engine is supported or not Parameter user_data The user data passed from mv_inference_foreach_supported_engine() @return @c true to continue with the next iteration of the loop, otherwise @c false to break out of the loop

@pre mv_inference_foreach_supported_engine()

Register this callback with TizenInteropCallbacks.register<mv_inference_supported_engine_cbFunction>() from package:tizen_interop_callbacks. Pass RegisteredCallback.interopCallback and RegisteredCallback.interopUserData to the native API. Used by: mv_inference_foreach_supported_engine.

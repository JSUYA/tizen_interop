  1. Pointer<Float> R,

@brief Computes the device's orientation based on the rotation matrix.

@details When it returns, the array values are filled with the result:

  • values0: azimuth, rotation around the Z axis.
  • values1: pitch, rotation around the X axis.
  • values2: roll, rotation around the Y axis. @since_tizen @if MOBILE 2.3 @elseif WEARABLE 2.3.1 @endif

@remarks Parameter R must be an array of 9 floats from sensor_util_get_rotation_matrix() \n Returned values are always arrays of 3 floats.

Parameter R A 9 element rotation matrix in the array Output parameter values An array of 3 floats to hold the result

@return #SENSOR_ERROR_NONE on success; Otherwise a negative error value @retval #SENSOR_ERROR_NONE Successful @retval #SENSOR_ERROR_INVALID_PARAMETER Invalid parameter

@see sensor_util_get_rotation_matrix()

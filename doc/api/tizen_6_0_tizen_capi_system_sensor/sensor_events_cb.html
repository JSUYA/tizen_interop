sensor_events_cb typedef

sensor_events_cb = sensor_events_cb

@brief Called when sensor events occur. @since_tizen 5.5

@remarks @a sensor should not be freed, it's managed by platform. @remarks @a events should not be freed and can be used only in the callback. To use outside the callback, make a copy.

Parameter sensor The corresponding sensor handle Parameter events The sensor events Parameter events_count The number of events Parameter user_data The user data passed to sensor_listener_set_events_cb()

@pre The sensor needs to be started regarding a listener handle, using sensor_listener_start().

Register this callback with TizenInteropCallbacks.register<sensor_events_cbFunction>() from package:tizen_interop_callbacks. Pass RegisteredCallback.interopCallback and RegisteredCallback.interopUserData to the native API. Used by: sensor_listener_set_events_cb.
